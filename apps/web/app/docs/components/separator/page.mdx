## Props

The Separator component accepts the following props:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `orientation` | `"horizontal"` \| `"vertical"` | `"horizontal"` | The orientation layout direction of the divider. |
| `decorative` | `boolean` | `true` | When `true`, it is ignored by screen readers. |
