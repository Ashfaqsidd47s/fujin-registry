## Props

The Input component extends the standard HTML input tag and supports the following customization parameters:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `flat` \| `bordered` \| `faded` \| `underlined` | `flat` | Outline style variation |
| `color` | `default` \| `primary` \| `secondary` \| `success` \| `warning` \| `danger` | `default` | Color theme |
| `size` | `sm` \| `md` \| `lg` | `md` | Padding and sizing constraints |
| `radius` | `none` \| `sm` \| `md` \| `lg` \| `full` | `md` | Corner border radius |
| `label` | `ReactNode` | `undefined` | Float/top section header text |
| `description` | `ReactNode` | `undefined` | Helpful bottom caption detail |
| `errorMessage` | `ReactNode` | `undefined` | Error feedback message display text |
| `isInvalid` | `boolean` | `false` | Marks field state as invalid/error |
| `startContent` | `ReactNode` | `undefined` | Left aligned icon/adornment |
| `endContent` | `ReactNode` | `undefined` | Right aligned icon/adornment |
