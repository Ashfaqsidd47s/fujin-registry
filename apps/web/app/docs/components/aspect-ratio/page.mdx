## Props

The AspectRatio component accepts the following props:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `ratio` | `number` | `1` (1:1) | The desired aspect ratio (e.g. `16 / 9` or `4 / 3`). |
