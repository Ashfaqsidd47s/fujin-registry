## Props

The Alert component accepts the following props:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `color` | `"default"` \| `"primary"` \| `"success"` \| `"warning"` \| `"danger"` \| `"info"` | `"default"` | The semantic coloring color variant of the alert. |
