## Props

The Checkbox component extends the Radix UI Checkbox root and adds custom styling variables:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `color` | `default` \| `primary` \| `secondary` \| `success` \| `warning` \| `danger` | `default` | Branding checked fill color |
| `size` | `sm` \| `md` \| `lg` | `md` | Dimensions |
| `label` | `ReactNode` | `undefined` | Right-side label layout text |
| `description` | `ReactNode` | `undefined` | Small caption helper text |
| `isInvalid` | `boolean` | `false` | Marks state error styling changes |
