## Props

The Card component supports standard layout elements and the following custom options:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `default` \| `transparent` \| `secondary` \| `tertiary` | `default` | Color intensity level |
| `shadow` | `none` \| `sm` \| `md` \| `lg` | `md` | Outer drop shadow size |
| `radius` | `none` \| `sm` \| `md` \| `lg` | `md` | Corner border radius |
| `isHoverable` | `boolean` | `false` | Enables vertical hover shifting |
| `isPressable` | `boolean` | `false` | Enables click scaling animations |
| `intensity` | `subtle` \| `default` \| `strong` | `default` | Glassmorphism layer strength |
| `vars` | `FujinSurfaceVars` | `undefined` | Key-value inline token overrides |
