## Props

The Textarea component extends the standard HTML textarea element and supports:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `flat` \| `bordered` \| `faded` \| `underlined` | `flat` | Visual style variation |
| `color` | `default` \| `primary` \| `secondary` \| `success` \| `warning` \| `danger` | `default` | Branding color theme |
| `size` | `sm` \| `md` \| `lg` | `md` | Dimensions |
| `radius` | `none` \| `sm` \| `md` \| `lg` \| `full` | `md` | Border radius |
| `label` | `ReactNode` | `undefined` | Section header label text |
| `description` | `ReactNode` | `undefined` | Bottom aligned description text |
| `errorMessage` | `ReactNode` | `undefined` | Validation error display text |
| `isInvalid` | `boolean` | `false` | Marks state error styling changes |
| `minRows` | `number` | `3` | Minimum vertical row span count |
| `maxRows` | `number` | `8` | Maximum auto-expand height limit |
