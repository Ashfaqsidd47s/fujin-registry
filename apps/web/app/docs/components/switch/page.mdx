## Props

The Switch component extends the Radix UI Switch primitive root and adds label layout supports:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `color` | `default` \| `primary` \| `secondary` \| `success` \| `warning` \| `danger` | `default` | Branding track color when checked |
| `size` | `sm` \| `md` \| `lg` | `md` | Dimensions |
| `label` | `ReactNode` | `undefined` | Switch label text |
| `description` | `ReactNode` | `undefined` | Supplemental detail description text |
