## Props

The Sheet component accepts the following props:

| Component | Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `SheetContent` | `side` | `"top"` \| `"bottom"` \| `"left"` \| `"right"` | `"right"` | The side of the screen where the sheet slides in from. |
