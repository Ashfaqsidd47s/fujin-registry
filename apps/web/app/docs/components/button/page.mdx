# Button

A premium, HeroUI-skinned button built on Radix Slot primitives.

---

## Installation

You can install either the lightweight CSS-transition version or the spring-animated motion version:

### Core (CSS Transitions)
```bash
npx shadcn@latest add http://localhost:3000/r/button.json
```

### Motion (Framer Motion)
```bash
npx shadcn@latest add http://localhost:3000/r/button-motion.json
```

---

## Props

The Button component accepts standard HTML button attributes and custom style variables:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `solid` \| `bordered` \| `flat` \| `light` \| `faded` \| `shadow` \| `ghost` | `solid` | Visual style variation |
| `color` | `default` \| `primary` \| `secondary` \| `success` \| `warning` \| `danger` | `default` | Semantic branding color |
| `size` | `sm` \| `md` \| `lg` | `md` | Dimensions |
| `radius` | `none` \| `sm` \| `md` \| `lg` \| `full` | `md` | Border radius |
| `isIconOnly` | `boolean` | `false` | Centers contents for icon layouts |
| `isLoading` | `boolean` | `false` | Displays a loading spinner |
| `startContent` | `ReactNode` | `undefined` | Icon or element at starting edge |
| `endContent` | `ReactNode` | `undefined` | Icon or element at ending edge |
