## Props

The Accordion component accepts the following props:

| Component | Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `Accordion` | `type` | `single` \| `multiple` | - | Determine whether single or multiple items can expand. |
| `Accordion` | `collapsible` | `boolean` | `false` | When `type` is `single`, allows closing the active item. |
| `AccordionItem` | `value` | `string` | - | Unique key for identifying the accordion panel. |
