## Props

The Tabs component extends the standard Radix UI Tabs layout components:

| Component | Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `Tabs` | `defaultValue` | `string` | - | The tab value to activate by default. |
| `Tabs` | `value` | `string` | - | Controlled active tab value. |
| `TabsTrigger` | `value` | `string` | - | Unique trigger value identifier. |
| `TabsContent` | `value` | `string` | - | The value that matches the parent trigger key. |
