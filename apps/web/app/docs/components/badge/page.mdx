## Props

The Badge component accepts standard HTML attributes and the following styling custom props:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `solid` \| `bordered` \| `flat` \| `faded` \| `shadow` | `solid` | Visual style variation |
| `color` | `default` \| `primary` \| `secondary` \| `success` \| `warning` \| `danger` | `default` | Semantic branding color |
| `radius` | `none` \| `sm` \| `md` \| `lg` \| `full` | `md` | Border radius |
| `size` | `sm` \| `md` \| `lg` | `md` | Dimensions |
