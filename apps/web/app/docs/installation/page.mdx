# Installation

Getting started with Fujin in your project is simple. Since Fujin is fully compatible with the shadcn/ui registry spec, you can use either shadcn or fujin CLI tools.

---

## 1. Initialize your project

If you are starting a fresh project, run the initializer:

```bash
npx shadcn@latest init
```

---

## 2. Configure registries

To add Fujin components, add our registry URL under the `registries` field inside your `components.json`:

```json
{
  "style": "new-york",
  "rsc": true,
  "tsx": true,
  "tailwind": {
    "config": "tailwind.config.js",
    "css": "app/globals.css"
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils"
  },
  "registries": {
    "@fujin": "https://fujin.dev/r/{name}.json"
  }
}
```

For local development or testing against this monorepo, point it to your local dev server:

```json
  "registries": {
    "@fujin": "http://localhost:3000/r/{name}.json"
  }
```

---

## 3. Add Components

Use the CLI command to fetch items directly from the registry:

### Core (Standard CSS Transitions)
```bash
npx shadcn@latest add http://localhost:3000/r/button.json
```

### Motion (Animated spring physics)
```bash
npx shadcn@latest add http://localhost:3000/r/button-motion.json
```
